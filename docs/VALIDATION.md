# 0.1.0 验证记录

日期：2026-11-13。使用合成资料，不包含维护者的真实经历或凭证。

## 已执行

- Apple Silicon Mac、macOS 15.3、Node 24.14.1：安装、测试、生产构建和本地启动。
- `npm run check`：3 个测试组通过，覆盖聊天格式、模型协议、真实本地 HTTP 服务以及合成 AI 对话 → 建议 → 人工确认 → JD 简历生成。
- 资料补丁只更新明确字段；保留其他资料；旧建议、重复确认与跨窗口版本冲突会阻止覆盖。
- 本地 Host / Origin 校验、修改请求会话令牌、模型密钥加密与接口脱敏。
- TXT/Markdown、PDF 和 DOCX 真实文字导入；生成 Word 后回读文字；JSON 备份、格式校验、恢复前副本和过期恢复冲突。
- Chrome 浏览器：个人资料编辑保存、基于资料新建简历、实时多页预览、版本载入、未保存内容离开提醒、桌面和 390px 窄屏布局。
- 浏览器 A4 PDF：3 页，35 条测试经历全部按顺序保留；逐页渲染检查无裁切。
- Word：OOXML 文件结构、文字回读与 macOS Quick Look 中文预览通过。开发用 LibreOffice headless 对中文字体有兼容问题，不能将其渲染结果视为 Word 实际显示结果；尚未在 Microsoft Word 中逐页人工验收。
- `npm audit`：当前锁文件的正式和开发依赖检查均为 0 个已知漏洞。PDF.js 已更新至修复所发现公告的版本；审计结果会随时间变化。

## 验证范围

云端协议通过模拟响应测试；未使用真实 API Key，也未将个人经历发送给任何模型。因此，真实供应商连接、具体模型的输出质量、费用及限额仍需使用者配置后自行核验。

Linux 自动检查由 GitHub Actions 执行。Windows 的实际安装和浏览器界面尚未实机验收。PDF 通过浏览器打印，不提供独立服务端排版引擎。不同 Word 编辑器、字体和浏览器的分页可能不同。
