## 真实浏览器与应用

Chrome 中实际完成：新建知识 → 分类、标签、事实确认 → 保存 → 粘贴带导航噪声的原始 JD → 本地整理并核对字段 → 保存岗位 → 从知识生成一页简历 → 上传合成色块图片 → 缩放与移动裁剪 → 保存照片版本。

另行完成照片删除、历史版本恢复、替换与再保存，直接核对版本照片内容一致性。知识条目完成显式关联、原始附件上传和按附件名搜索。实际预览可见完整中文与可选照片。

Microsoft Word 以只读方式打开独立中文合成样例，切换页面视图后状态栏显示“第 1 页，共 1 页”；随后仅关闭该样例，没有修改其他已打开文档。该项是小型样例抽验，不代表所有编辑器、系统与字体组合均一致。

## 排版问题与修复

验收发现 macOS 的 headless 排版引擎可能只发现内置西文字体，出现中文缺字而页数仍为一页。修复为给本地转换进程显式提供系统/用户字体目录和私人缓存；安装 Noto 中文字体，并增加逐字检查中文频次的守卫。最终合成样例的中文、数字与照片均通过实际 PDF 验证。不以“转换成功”或“只有一页”单独作为排版成功证据。

## 验证边界

云端模型采用合成响应测试，覆盖真实 HTTP API、协议与结果守卫；没有验证具体收费模型的实际输出质量、费用或限额。真实用户仍需配置自己的模型并核对 JD、资料缺口和最终简历。

Word 与 LibreOffice 是不同排版引擎。导出的 DOCX 经过本机 LibreOffice 一页验证，PDF 固定为该次实际输出；在其他电脑、字体或 Word 版本中重排后仍可能改变页数。跨机器提交建议使用 PDF。

Windows 尚未实机验收；Linux 的实际结果以本仓库 GitHub Actions 为准。知识条目是轻量 Markdown/双链系统，不提供 Notion 数据库视图、拖拽块或 Obsidian 插件兼容。单附件 12 MB，完整快照 96 MB；超限会拒绝保存并保留编辑内容。
